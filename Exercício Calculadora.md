# Exercício — Criando uma Calculadora com HTML, CSS e JavaScript

Seu objetivo é desenvolver uma calculadora funcional utilizando:

* HTML
* CSS
* JavaScript

A calculadora deverá possuir interface visual, botões interativos e realizar operações matemáticas básicas.

---

# Objetivo

Criar uma calculadora capaz de:

* somar
* subtrair
* multiplicar
* dividir
* limpar o visor
* mostrar números digitados pelo usuário

---

# Requisitos do HTML

Sua página deve conter:

* uma `div` principal para a calculadora
* um visor (`input` ou `div`) para mostrar os números
* botões numéricos de `0` até `9`
* botão de:

  * soma (`+`)
  * subtração (`-`)
  * multiplicação (`×`)
  * divisão (`÷`)
  * igual (`=`)
  * limpar (`C`)

Organize os botões em formato de calculadora real.

---

# Requisitos do CSS

A calculadora deve possuir:

* layout centralizado na tela
* botões organizados em grade
* cores personalizadas
* efeito hover nos botões
* bordas arredondadas
* sombra na calculadora

Você pode criar:

* tema escuro
* tema claro
* tema retrô
* tema moderno

---

# Requisitos do JavaScript

Utilize JavaScript para:

* capturar cliques dos botões
* mostrar os números no visor
* armazenar operações
* calcular o resultado
* limpar o visor

---

# Desafios Extras

## Extra 1 — Teclado

Permita que o usuário utilize o teclado do computador para digitar os números.

---

## Extra 2 — Histórico

Mostre uma lista das operações realizadas anteriormente.

Exemplo:

```txt
10 + 5 = 15
7 × 3 = 21
20 ÷ 2 = 10
```

---

## Extra 3 — Botão apagar

Crie um botão:

* `←`

Ele deve apagar apenas o último número digitado.

---

## Extra 4 — Tema dinâmico

Adicione um botão para trocar entre:

* modo claro
* modo escuro

---

# Objetivo Final

Ao terminar, sua calculadora deve:

* possuir visual agradável
* funcionar corretamente
* responder aos cliques
* realizar operações matemáticas sem erros

Desafio bônus:
tente fazer sua calculadora parecida com a do celular.
